# Design v2 + Today-first IA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the stock-looking UI with the Flighty-inspired design system, restructure the app into Today/Plan/Activities tabs, and ship the Today screen (week strip, day card, comp countdown) mapped from a new `user_programs.start_date`.

**Architecture:** Extended Unistyles tokens + a custom component kit in `src/components/ui/`; expo-router tab group `(tabs)` with a custom floating pill tab bar; pure, tested date-mapping functions (`currentProgramPosition`, `nextCompDay`) driven by a new `start_date` column written on programme selection. `@expo/ui` is removed from all screens.

**Tech Stack:** Unistyles v3, expo-linear-gradient, expo-symbols (installed), expo-router Tabs, Supabase migration.

**Spec:** `docs/superpowers/specs/2026-10-14-design-v2-today-ia.md` — its Tokens, Components, and IA sections are binding contracts for this plan; read it before every task. (Parent specs: workout-logging + styling-foundation designs.)

## Global Constraints

- All visual values (hex, sizes, weights, radii, shadows, gradients) come from the spec's Tokens section verbatim, defined once in `src/styles/unistyles.ts` — zero hex literals outside that file (grep-gated as before).
- `@expo/ui` imports must be GONE from `src/` by the end of Task 2 (grep-gated); components come from `src/components/ui/`.
- System font only; numerals that represent data use `fontVariant: ['tabular-nums']`.
- Deps only via `npx expo install` (expo-linear-gradient; expo-blur only if the pill bar uses it). Native module additions require noting that the human must rebuild the dev client (`npx expo run:ios`) — expo-linear-gradient and expo-blur are in the Expo SDK and ARE in the current dev client only if already compiled; check `ios/Podfile.lock` and say so in the report.
- Schema change via forward-only migration; `supabase db push`.
- Every task ends with `npx jest --silent`, `npx expo lint`, `npx tsc --noEmit` clean + iOS bundle check (background `expo start` + curl, 0 errors, kill server). Stage only task files.
- Date logic: local calendar dates only (construct from Y/M/D parts; never `toISOString()` for day math).

## Review Focus

1. **Timezone/midnight day-shift bugs** — `currentProgramPosition`/`nextCompDay` must be pinned by tests including: today == start_date, Sunday (day 7) boundaries, week boundaries, before-start and after-end clamps, and a UTC+11-style local date where UTC conversion would shift the day. → Task 1 TDD.
2. **start_date backfill** — the existing selected row must get a valid Monday; selecting again overwrites consistently. → Task 1 migration + verify query.
3. **Tab restructure breaking routes** — `/program/...` and typed routes must survive the move of the home screen into `(tabs)`; deep links from Plan→overview→week→day all still work. → Task 2 bundle + manual nav pass.
4. **DayStrip correctness** — dots reflect the selected week's day kinds; today ring only when the displayed week is the current week. → Task 2 component logic + Task 1 selectors.
5. **Dark mode on new components** — gradient text roles, card shadows, and the done/comp tints must be legible in both themes. → human visual pass at the end of Task 2.
