# Programme Browsing & Selection (Slice 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the 8-Week Peak programme in Pull Up backed by Supabase: browse programme list → overview → week → day, and set an active programme per (anonymous) user.

**Architecture:** Hosted Supabase project (`uzkshlhlvlslnwygpejp`) with a relational programme schema (`programs → program_weeks → program_days → day_exercises`) seeded by SQL migration; Expo Router screens fetch via supabase-js + React Query; anonymous auth established silently at app bootstrap; `user_programs` upsert records the active programme.

**Tech Stack:** Expo SDK 57 / React Native 0.86 / expo-router, TypeScript, `@supabase/supabase-js` (session storage via `expo-sqlite/localStorage/install`), `@tanstack/react-query`, `react-native-markdown-display`, `jest-expo`, Supabase CLI migrations.

**Spec:** `docs/superpowers/specs/2026-10-14-program-browsing-design.md`

## Global Constraints

- Install JS deps with `npx expo install <pkg>` (never npm/yarn/pnpm add) so versions match SDK 57.
- Routes live in `src/app/`; all non-route code lives outside it (AGENTS.md).
- Env vars: `EXPO_PUBLIC_SUPABASE_URL`, `EXPO_PUBLIC_SUPABASE_KEY` — already in `.env.local` (gitignored). Never commit real values; `.env.example` carries placeholders.
- App display name is **Pull Up** (`app.json` → `expo.name`).
- Supabase schema changes only via migrations in `supabase/migrations/`, applied with `supabase db push`. No dashboard-made schema edits.
- All tables have RLS enabled; programme tables are read-only to clients.
- Every task ends with `npx expo lint` and `npx tsc --noEmit` passing.
- Do not create `ios/`/`android/` directories; no native config edits outside `app.json`.
- **UI: no custom design system, no decorative styling.** Use `@expo/ui/universal` components (`Host`, `List`, `Section`, `Button`, `Text` — Expo Go supported, every component wrapped in a `Host`) and default-styled RN primitives (`Text`, `ScrollView`, `ActivityIndicator`). Inline styles only for spacing/layout (padding, gap, flex). A styling library (GlueStack etc.) may come later; do not add one now. Check the @expo/ui docs (`https://docs.expo.dev/versions/v57.0.0/sdk/ui/`) before using an unfamiliar prop; if a `Host` embedded in a scroll view won't auto-size, set `matchContents` or an explicit height.

## Review Focus

Spec-implied behaviors no test exercises by default; each line's pinning test/check is added to the owning task:

1. **Nested rows arrive unordered** — PostgREST gives no order guarantee on embedded tables; weeks/days/exercises must render in `position` order. → mapping unit tests, Task 4.
2. **Non-lifting days (court/rest/comp)** — must appear in the week view with notes inline and never navigate to an empty exercise screen. → mapping test (empty `exercises`) Task 4; week-screen behavior Task 7.
3. **Re-selecting / switching programme** — second select must upsert (update), not fail on the `user_id` unique constraint. → upsert uses `onConflict: 'user_id'`, Task 6 test + manual check.
4. **Supabase unreachable at launch** — auth bootstrap failure shows a blocking retry screen; query screens show error + retry, never an infinite spinner. → Task 3 (bootstrap) and Task 5 (list) manual airplane-mode check in Task 8.
5. **Markdown prose contains tables** (weekly rules, fuelling, optional-court tables) — renderer must support markdown tables legibly on a phone. → Task 6 manual verification step of overview rendering.

```sql
  id uuid primary key default gen_random_uuid(),
  slug text not null unique,
  name text not null,
  summary text not null,
  description text not null,
  created_at timestamptz not null default now()

  id uuid primary key default gen_random_uuid(),
  program_id uuid not null references public.programs(id) on delete cascade,
  position int not null,
  name text not null,
  phase text not null,
  description text,
  unique (program_id, position)

create table public.program_days (
  id uuid primary key default gen_random_uuid(),
  week_id uuid not null references public.program_weeks(id) on delete cascade,
  position int not null,
  name text not null,
  kind text not null check (kind in ('lifting', 'court', 'rest', 'comp')),
  notes text,
  unique (week_id, position)
);

create table public.day_exercises (
  id uuid primary key default gen_random_uuid(),
  day_id uuid not null references public.program_days(id) on delete cascade,
  position int not null,
  exercise_name text not null,
  sets int,
  reps text,
  load text,
  notes text,
  unique (day_id, position)
);

create table public.user_programs (
  user_id uuid primary key references auth.users(id) on delete cascade,
  program_id uuid not null references public.programs(id) on delete cascade,
  selected_at timestamptz not null default now()
);

alter table public.programs enable row level security;
alter table public.program_weeks enable row level security;
alter table public.program_days enable row level security;
alter table public.day_exercises enable row level security;
alter table public.user_programs enable row level security;

create policy "programs readable by authenticated"
  on public.programs for select to authenticated using (true);
create policy "weeks readable by authenticated"
  on public.program_weeks for select to authenticated using (true);
create policy "days readable by authenticated"
  on public.program_days for select to authenticated using (true);
create policy "exercises readable by authenticated"
  on public.day_exercises for select to authenticated using (true);

create policy "own user_programs select"
  on public.user_programs for select to authenticated using (user_id = (select auth.uid()));
create policy "own user_programs insert"
  on public.user_programs for insert to authenticated with check (user_id = (select auth.uid()));
create policy "own user_programs update"
  on public.user_programs for update to authenticated
  using (user_id = (select auth.uid())) with check (user_id = (select auth.uid()));
create policy "own user_programs delete"
  on public.user_programs for delete to authenticated using (user_id = (select auth.uid()));
```

```js
import { createClient } from '@supabase/supabase-js';

const supabase = createClient(
  process.env.EXPO_PUBLIC_SUPABASE_URL,

);

const fail = (msg) => { console.error(`FAIL: ${msg}`); process.exit(1); };

if (!program) fail('programme 8-week-peak not found');
if (program.program_weeks.length !== 7) fail(`weeks: ${program.program_weeks.length} !== 7`);
const days = program.program_weeks.flatMap((w) => w.program_days);
if (days.length !== 49) fail(`days: ${days.length} !== 49`);
const bareLifting = days.filter((d) => d.kind === 'lifting' && d.day_exercises.length === 0);
if (bareLifting.length > 0) fail(`${bareLifting.length} lifting day(s) with no exercises`);

console.log('OK: 1 programme, 7 weeks, 49 days, all lifting days have exercises');
```

- [ ] **Step 3: Auth bootstrap** (`src/lib/auth.tsx`)

```tsx
import { createContext, useContext, useEffect, useState, type ReactNode } from 'react';
import { ActivityIndicator, Button, Text, View } from 'react-native';
import type { Session } from '@supabase/supabase-js';
import { supabase } from './supabase';

const SessionContext = createContext<Session | null>(null);

export function useSession(): Session {
  const session = useContext(SessionContext);
  if (!session) throw new Error('useSession must be used inside <AuthGate>');
  return session;
}

export function AuthGate({ children }: { children: ReactNode }) {
  const [session, setSession] = useState<Session | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [attempt, setAttempt] = useState(0);

  useEffect(() => {
    let cancelled = false;
    (async () => {
      setError(null);
      const { data } = await supabase.auth.getSession();
      if (cancelled) return;
      if (data.session) {
        setSession(data.session);
        return;
      }
      const { data: anon, error: anonError } = await supabase.auth.signInAnonymously();
      if (cancelled) return;
      if (anonError) setError(anonError.message);
      else setSession(anon.session);
    })();
    return () => { cancelled = true; };
  }, [attempt]);

  if (error) {
    return (
      <View style={{ flex: 1, justifyContent: 'center', alignItems: 'center', gap: 12, padding: 24 }}>
        <Text>Couldn't connect. Check your connection and try again.</Text>
        <Button title="Retry" onPress={() => setAttempt((a) => a + 1)} />
      </View>
    );
  }
  if (!session) {
    return (
      <View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
        <ActivityIndicator />
      </View>
    );
  }
  return <SessionContext.Provider value={session}>{children}</SessionContext.Provider>;
}
```

```ts
import type { PhaseEntry, Program, ProgramWeek, RawProgram } from './types';

const byPosition = <T extends { position: number }>(a: T, b: T) => a.position - b.position;

export function toProgram(raw: RawProgram): Program {
  return {
    id: raw.id,
    slug: raw.slug,
    name: raw.name,
    summary: raw.summary,
    description: raw.description,
    weeks: [...raw.program_weeks].sort(byPosition).map((week) => ({
      id: week.id,
      position: week.position,
      name: week.name,
      phase: week.phase,
      description: week.description,
      days: [...week.program_days].sort(byPosition).map((day) => ({
        id: day.id,
        position: day.position,
        name: day.name,
        kind: day.kind,
        notes: day.notes,
        exercises: [...day.day_exercises].sort(byPosition).map((exercise) => ({
          id: exercise.id,
          position: exercise.position,
          exerciseName: exercise.exercise_name,
          sets: exercise.sets,
          reps: exercise.reps,
          load: exercise.load,
          notes: exercise.notes,
        })),
      })),
    })),
  };
}

export function buildPhaseTimeline(weeks: ProgramWeek[]): PhaseEntry[] {
  return weeks.map((week) => ({
    weekName: week.name,
    phase: week.phase,
    compDayName: week.days.find((day) => day.kind === 'comp')?.name ?? null,
  }));
}
```

```ts
import { supabase } from '@/lib/supabase';
import { toProgram } from './mapping';
import type { Program, ProgramSummary, RawProgram } from './types';

const PROGRAM_SELECT = `
  id, slug, name, summary, description,
  program_weeks (
    id, position, name, phase, description,
    program_days (
      id, position, name, kind, notes,
      day_exercises ( id, position, exercise_name, sets, reps, load, notes )
    )
  )
`;

export async function fetchPrograms(): Promise<ProgramSummary[]> {
  const { data, error } = await supabase
    .from('programs')
    .select('id, slug, name, summary')
    .order('name');
  if (error) throw error;
  return data;
}

export async function fetchProgram(id: string): Promise<Program> {
  const { data, error } = await supabase
    .from('programs')
    .select(PROGRAM_SELECT)
    .eq('id', id)
    .single();
  if (error) throw error;
  return toProgram(data as unknown as RawProgram);
}

export async function fetchActiveProgramId(userId: string): Promise<string | null> {
  const { data, error } = await supabase
    .from('user_programs')
    .select('program_id')
    .eq('user_id', userId)
    .maybeSingle();
  if (error) throw error;
  return data?.program_id ?? null;
}

export async function selectProgram(userId: string, programId: string): Promise<void> {
  const { error } = await supabase
    .from('user_programs')
    .upsert(
      { user_id: userId, program_id: programId, selected_at: new Date().toISOString() },
      { onConflict: 'user_id' },
    );
  if (error) throw error;
}
```

```ts
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query';
import { useSession } from '@/lib/auth';
import { fetchActiveProgramId, fetchProgram, fetchPrograms, selectProgram } from './api';

export function usePrograms() {
  return useQuery({ queryKey: ['programs'], queryFn: fetchPrograms });
}

export function useProgram(id: string) {
  return useQuery({ queryKey: ['programs', id], queryFn: () => fetchProgram(id) });
}

export function useActiveProgram() {
  const session = useSession();
  return useQuery({
    queryKey: ['active-program', session.user.id],
    queryFn: async () => {
      const programId = await fetchActiveProgramId(session.user.id);
      return programId ? { programId } : null;
    },
  });
}

export function useSelectProgram() {
  const session = useSession();
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: ({ programId }: { programId: string }) => selectProgram(session.user.id, programId),
    onSuccess: () => queryClient.invalidateQueries({ queryKey: ['active-program', session.user.id] }),
  });
}
```
