# Today Page v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the Today tab as a Nike-style scrolling week checklist (all 7 days, completion checks, segmented week progress) with Runna's utility chrome (week line + glanceable/jump-nav day strip) and a context-aware floating action button replacing the inline start CTAs.

**Architecture:** Pure state-derivation functions (week completion map, day states, floating-button state) over the existing workout store + programme schedule; new presentational components (ProgressSegments, WeekDayCard, FloatingAction); a restructured `(tabs)/index.tsx` with scroll-to-day anchors; ResumeBanner retired from Today.

**Tech Stack:** Existing stack only — no new dependencies. Plain StyleSheet + useTheme tokens; Expo Go-compatible.

**Spec:** `docs/superpowers/specs/2026-10-14-today-v2-design.md` (binding; supersedes design-v2's Today section). Read it before every task.

## Global Constraints

- Tokens only (zero hex outside `src/styles/theme.ts`); module-level `createStyles` + `useThemedStyles`; `fontVariant: ['tabular-nums']` on data numerals.
- All store reads via existing hooks/`use$`; all starts via `startWorkoutOrPrompt` (the start-guard — never bypass it); no direct supabase access.
- Rules of Hooks: all hooks before early returns on the Today screen (the existing IIFE pattern may be refactored but never into conditional hooks).
- Every task: `npx jest --silent` (97+ green + new tests), `npx expo lint`, `npx tsc --noEmit`, iOS bundle check (port ~8096; 8081 Docker-held), kill server. Scoped staging; never `git add -A`.
- Peter owns all manual/visual QA — no simulator interaction.

## Review Focus

1. **Day-state correctness at boundaries** — today==first/last day of week, week rollover, finished programme, before-start preview: 'missed' must never apply to today or future days, and never to non-lifting days. → Task 1 TDD with concrete dates.
2. **Floating-button precedence** — active workout beats today's session beats fallback; the guard prompt still fires when starting over an active workout from the fallback path. → Task 1 pure tests + Task 2 wiring.
3. **Scroll-anchor drift** — strip-tap must scroll to the right card after layout changes (promoted today card is taller). → onLayout-recorded offsets, not index math; Task 2.
4. **Floating button clearance** — last card must clear button + glass tab bar in both themes; content inset behavior preserved (`contentInsetAdjustmentBehavior="automatic"` stays). → Task 2 + Peter's visual pass.
5. **ResumeBanner removal** — no dangling imports; resume reachable via the floating button in ALL Today states (incl. no-programme and finished). → Task 2 grep + states.

### Task 1: Pure derivations (TDD) + components

**Files:**
- Create: `src/features/workouts/today-state.ts`, `src/features/workouts/__tests__/today-state.test.ts`, `src/components/ui/progress-segments.tsx`, `src/components/ui/week-day-card.tsx`, `src/components/ui/floating-action.tsx`
- Modify: `src/features/workouts/hooks.ts` (+ `useWeekCompletion(days)` reactive wrapper)

**Interfaces (Task 2 consumes):**
- `today-state.ts` (pure, no store imports):
  - `weekCompletion(workouts: Record<string, Workout>, dayIds: string[]): Record<string, boolean>` (finished, non-deleted, matching program_day_id);
  - `dayState(day: ProgramDay, todayPosition: number, completed: boolean): 'today' | 'done' | 'missed' | 'upcoming' | 'info'` — rules per spec (lifting-only missed/done precedence: done beats today beats missed; non-lifting → 'info' unless position === todayPosition where 'today'-styling still applies visually — expose that as a separate boolean `isToday` instead if cleaner; state your shape);
  - `floatingAction(args: { activeWorkout: Workout | null; todayDay: ProgramDay | null; todayCompleted: boolean }): { kind: 'resume'; workoutId: string } | { kind: 'startToday' } | { kind: 'startEmpty' }`.
- `ProgressSegments({ total, filled })` — Nike-style segment bar + "Workouts completed: X of N" caption (label type).
- `WeekDayCard({ day, state, isToday, onPress? })` — builds on the WorkoutCard look: kind edge, TODAY eyebrow when isToday, done check, "Missed" caption, muted/quiet variants per state.
- `FloatingAction({ label, onPress })` — pill above the tab bar: absolute, bottom = safe-area inset + tab-bar clearance (use `useSafeAreaInsets`; a TAB_BAR_CLEARANCE constant is acceptable, exported for reuse), cardElevated/accent bg per spec feel (accent bg + onAccent label), `shadow.float`.
